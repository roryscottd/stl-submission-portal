Google Drive Auto-Sync Setup (Free via Google Apps Script)

Deploy this 1-time script in your Google account so every student STL is automatically saved into class subfolders inside your Drive folder.

  1. Open script.google.com and click New Project.
  2. Delete any existing code, paste the protected script below (your Secret Key & all 30 classes are already embedded), and click Save.
  3. Click Deploy → New deployment, choose Web app, set Execute as to Me and Who has access to Anyone, then click Deploy.
  4. Copy your Web app URL, paste it below to test, and optionally paste both the URL and Secret Key into BAKED_WEB_APP_URL and BAKED_SECRET_KEY at the top of this HTML file before pasting into Google Sites.
